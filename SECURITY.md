# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public GitHub issue.

Report it privately through Spry Web Tech's contact form at https://sprywebtech.com/contact/ and include:

- The affected plugin version
- WordPress and PHP versions
- Web-server configuration
- Reproduction steps
- Potential impact
- Any suggested mitigation

Please avoid including real credentials, private keys, database exports, or production customer information.
